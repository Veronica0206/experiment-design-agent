These examples were captured from an authorized complete installation using
synthetic inputs. They illustrate the complete system's canonical reporting
contract; they were not generated by this public clone, and the proprietary
statistical engines used to produce them are not distributed here.

The A/B and single-endpoint examples are historical snapshots captured on
2026-08-14 against public reporting surface `32d6c616`. The fractional-
factorial example was regenerated on 2026-08-26 from the reviewed complete
installation after the public generator/relation contract changed. The public
release manifest pins the exact example bytes. The fixed regression attestation
passed all five engine suites at each capture.
Treat these files as illustrative evidence, not as executable output, a
current-release attestation, or evidence that the public clone can perform the
analyses.
