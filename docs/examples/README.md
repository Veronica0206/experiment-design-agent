# Example reports

[single-endpoint-sample-size-report.md](single-endpoint-sample-size-report.md)
is an illustrative canonical report from synthetic inputs executed by the local
R engine. Its documentation identity and verification envelope were constructed
locally using deterministic design and contract checks, not issued by an MCP
server. Regression and replay attestations are not claimed. It is not a result
for a user's study and does not replace executing the current engine.

The runnable examples and their explicit simulation settings are documented in
[the public R module](../../vera-experiment-designing/README.md).
