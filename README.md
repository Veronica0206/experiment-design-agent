# Experiment Design Agent — Private Release Candidate

This repository is a fresh review checkpoint for the non-proprietary runtime,
verification hooks, agent harness, MCP server, tests, and release tooling.

The proprietary skill packages are intentionally omitted and do not appear in
this repository's history. Consequently, this checkpoint is not a complete
runnable distribution and must not be treated as approval for public release.

Keep the repository private until its public documentation, licensing,
distribution packaging, and end-to-end installation path have been reviewed.
